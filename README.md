## About

ReimaginedOS is a **Windows optimization playbook** built for [AME Wizard](https://github.com/Ameliorated-LLC/trusted-uninstaller-cli/releases/tag/0.8.4).

The goal is simple: make Windows **lighter, cleaner and more configurable** without forcing one giant collection of tweaks onto every system.

Every part of the playbook is optional.

> **Choose what you need. Skip what you don't.**

### Focus

**⚡ Performance**  
Reduce unnecessary background activity, services and scheduled tasks.

**🧹 Debloat**  
Remove Windows components and applications you don't use.

**🔒 Privacy**  
Configure telemetry, diagnostics and privacy-related settings.

**🎮 Gaming**  
Optional power, network, latency and scheduling tweaks.

---

## Features

### ⚡ Performance

- Service configuration
- Scheduled task management
- Power plans
- Timer-related settings
- CPU / GPU tweaks
- General system optimization

### 🧹 Debloat

- Microsoft Store
- OneDrive
- Widgets
- Copilot
- Microsoft Teams
- Optional Windows components
- Unnecessary background services

### 🔒 Privacy

- Telemetry configuration
- Diagnostic data
- Tracking-related services
- Windows privacy settings
- Windows Update configuration

### 🎮 Gaming

- Power configuration
- Network settings
- Latency-related tweaks
- Background process reduction
- Timer and scheduling configuration

> Results depend on your hardware, drivers, games and existing Windows configuration.

---

## 🛡️ Defender

Defender is **optional**.

You can keep Microsoft Defender enabled, modify selected settings, or disable it if you use another security solution.

> **⚠️ Disabling security features can reduce system security.**

---

## 🛠️ ToolBox

The **ReimaginedOS ToolBox** is a lightweight companion application for managing commonly used Windows settings after the initial playbook run.

| System | Performance | Network | Security |
|:---:|:---:|:---:|:---:|
| OS / CPU / RAM / GPU | CPU / GPU tweaks | Wi-Fi / Bluetooth | Defender |
| Power plans | Services | Network settings | Windows Update |
| System info | Performance settings | — | Privacy |

The idea is to keep the controls you actually use in one place.

## How it works

```text
Windows
   │
   ▼
AME Wizard
   │
   ▼
ReimaginedOS
   │
   ├── Performance
   ├── Debloat
   ├── Privacy
   ├── Gaming
   └── System settings
   │
   ▼
Your Windows setup
```

**1. Choose** — Open the playbook in AME Wizard.

**2. Review** — Go through the available options.

**3. Configure** — Select only what you want.

**4. Apply** — Let AME Wizard handle the changes.

**5. Fine-tune** — Use the ToolBox afterwards.

## ❓ FAQ

<details>
<summary><strong>What is ReimaginedOS?</strong></summary>

<br>

ReimaginedOS is a Windows optimization playbook for AME Wizard focused on performance, privacy, debloating and optional gaming-oriented configuration.

</details>

<details>
<summary><strong>Is it a custom Windows ISO?</strong></summary>

<br>

No. ReimaginedOS is an **AME Wizard playbook**, not a modified Windows ISO.

</details>

<details>
<summary><strong>Do I need AME Wizard?</strong></summary>

<br>

Yes. ReimaginedOS is designed to run through AME Wizard.

[Get AME Wizard](https://github.com/Ameliorated-LLC/trusted-uninstaller-cli/releases/tag/0.8.4)

</details>

<details>
<summary><strong>Is it released?</strong></summary>

<br>

Not yet. The project is currently being developed and tested.

</details>

<details>
<summary><strong>Can I keep Windows Defender?</strong></summary>

<br>

Yes. Defender-related changes are optional.

</details>

<details>
<summary><strong>Will it increase my FPS?</strong></summary>

<br>

There is no guaranteed FPS increase. ReimaginedOS focuses on reducing unnecessary overhead and providing optional gaming-oriented configuration.

Results depend on your hardware, drivers, games and Windows setup.

</details>

<details>
<summary><strong>Is a clean Windows installation recommended?</strong></summary>

<br>

Yes. A fresh installation helps avoid conflicts with existing system modifications and software.

</details>
