ReimaginedOS is a Windows playbook for AME Wizard 🧙. The idea is simple: Windows should be **fast, clean and yours** — not a storefront with a built-in OS. And the best part? **You decide what gets applied.** Every tweak is a question you answer, so nothing happens without your say-so.

## What it does

- 🪶 **Fewer processes** — background services and scheduled tasks get gutted so hard Task Manager looks empty
- 🧨 **Debloat that actually works** — Store, Copilot, Widgets, OneDrive, Teams and co. removed for good, even on modern Windows
- 🕶️ **Privacy first** — telemetry blocked everywhere, tracking off, updates under your control
- 🎮 **Gamer approved** — power plans, timers and network tuning for max FPS and low latency
- 🐕 **Defender on a leash** — tone it down, or delete it entirely. Your call
- 🧹 **Tidy desktop** — clean shortcuts, custom branding, wallpaper and an apps folder for the rest

## The ToolBox

ReimaginedOS brings its own helper app to keep things sharp after the first run:

- ⚡ One-click maintenance — flush DNS, purge RAM, rebuild icon cache, restart Explorer
- 🎛️ Toggles for Defender, Windows Update, services and telemetry
- 📊 System info at a glance — OS, CPU, RAM, GPU, power plan

## Supported systems

Currently targeting AMD64 builds:

- Windows 10 22H2
- Windows 11 23H2
- Windows 11 24H2 (+ LTSC)
- Windows 11 25H2

## How it will work

Once released:

1. Grab **AME Wizard** and the playbook from the releases
2. Drag-and-drop the playbook into AME Wizard
3. Tick what you want, skip what you don't — then let it work

> 💡 A fresh, stock Windows install is recommended before applying.
