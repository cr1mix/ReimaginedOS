ReimaginedOS is a Windows optimization playbook for [AME Wizard](https://github.com/Ameliorated-LLC/trusted-uninstaller-cli/releases/tag/0.8.4) . The idea is simple: Windows should be **fast, clean and yours** — not a storefront with a built-in OS. Every tweak is a question you answer, so nothing gets applied without your say-so.

[![AME Wizard](https://img.shields.io/badge/AME%20Wizard-0078D6?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Ameliorated-LLC/trusted-uninstaller-cli/releases/tag/0.8.4)

## ✨ What it does

- 🪶 **Drops the process count like crazy** — background services and scheduled tasks get gutted so hard that Task Manager looks empty
- 🧨 **Debloat that actually works** — Microsoft Store, Copilot, Widgets, OneDrive, Teams and the rest, removed for good even on modern Windows builds
- 🕶️ **Privacy by default** — telemetry blocked at every level, tracking off, Windows Update under your control
- 🎮 **Gaming-first tuning** — power plans, timers and network settings squeezed for maximum FPS and minimum latency
- 🛡️ **Defender, your way** — *remove it*, *keep it*, or anything in between. Your system, your choice
- 🧹 **Clean desktop** — curated shortcuts, custom branding and wallpaper, and an `apps` folder for everything else

## 🛠️ The ToolBox

ReimaginedOS ships with a lightweight helper app to keep your system sharp after the first run:

- ⚡customizable cpu gpu tweaks , services wifi , bluetooth all in one app
- 🎛️ Toggles for Defender, Windows Update, services and telemetry
- 📊 System info at a glance — OS, CPU, RAM, GPU, power plan

## 🚀 Getting started

Once released:

1. Grab **AME Wizard** and the playbook from the releases
2. Drag-and-drop the playbook into AME Wizard
3. Tick what you want, skip what you don't — then let it work

> 💡 A fresh, stock Windows installation is recommended before applying the playbook.
